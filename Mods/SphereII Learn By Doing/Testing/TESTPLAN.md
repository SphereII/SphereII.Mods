# LBD test plan

_Generated by `Testing/lbd_audit.py` - do not hand-edit._

## How to run

1. New character (the Init buff only runs when `$lbd_xp_melee_base` is 0, so retuned values need a fresh character, or a Grandpa's Forgettin' Elixir).
2. Console: `dm`, then `buff god`. Every LBD debug line is gated behind the `god` buff - without it the log stays silent.
3. Install the `SphereII Learn By Doing Test Harness` modlet so level-ups and the silent award paths reach the log.
4. Work the checklist below. The perk window draws an LBD progress bar under each perk, attribute and skill row - that is the live visual confirmation.
5. Feed the log to `lbd_logparse.py` for coverage and real per-level timings.

`setcvar $x 0` **deletes** the cvar rather than zeroing it (SCore treats 0 as remove). An unset cvar reads as 0, so it works for a reset, but it will not appear in any dump until something writes it again.
